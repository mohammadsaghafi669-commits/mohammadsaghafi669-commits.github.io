# NEXORA Team — GitHub Pages Resume

## Deploy
1. Create a GitHub repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `NEXORA_International_CV_Updated.pdf`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save. Your site will appear at `https://YOUR-USERNAME.github.io/`.

Replace `YOUR-USERNAME` with the actual GitHub username.

The page uses the supplied resume as its content basis. Review project wording and dates before publishing.
